# Decisions Log

Use this file to record meaningful decisions so future agent sessions do not re-litigate them.

Record:
- source conflicts,
- scope decisions,
- structural file-layout choices,
- citation-policy interpretations,
- theorem/proof/result handling decisions,
- figure-interpretation decisions when the figure spec is ambiguous,
- PDF style or formatting choices that are not obvious from the spec alone.
