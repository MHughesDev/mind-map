# Legacy Master Template

This file is kept only as a migration reference for older projects that predate the expanded `PROJECT_SPEC.md`.

## Important

- Do not use this file as the controlling spec for new work.
- The controlling spec for this repository is `PROJECT_SPEC.md`.
- If you need a quick-fill helper, use `templates/quick_spec_short_form.md` and merge the results into `PROJECT_SPEC.md`.

## Migration Rule

When older materials exist in this format, migrate them into `PROJECT_SPEC.md` before asking the agent to execute the project.

Use the expanded spec sections as the destination of truth:
- execution model and stop conditions,
- research content bank,
- source priority and conflict policy,
- claim and evidence map,
- citation policy and citation map,
- section-by-section blueprint,
- theorem/proof/equation inventories,
- figure/table/PDF-style plans.
