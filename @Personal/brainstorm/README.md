# Brainstorm

Structured working notes for turning **high-quality sources** (papers, reports, codebases, internal docs) into **new artifacts**: designs, systems, essays, or product directions.

Each session is meant to be **repeatable**: same phases, different inputs. Nothing here commits you to build anything.

## Contents

| File | Purpose |
|------|---------|
| [Agentic research → creation procedures](./agentic-research-synthesis-procedures.md) | Step-by-step agent workflows: ingest, extract claims, stress-test, synthesize, and ship an output |
| [Session template](./session-template.md) | Blank scaffold for a single brainstorming run (copy per topic) |

## How to use

1. Copy `session-template.md` to a new file named for your topic.
2. Drop in **sources** (paths, URLs, or pasted abstracts).
3. Run the **phases** in the procedures doc in order, or parallelize “extract” across sources if you use multiple agents.
4. End with **decisions** and **open questions** so the next session does not restart from zero.
